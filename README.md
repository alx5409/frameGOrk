# FrameGOrk
A minimal backend framework in Go built as a learning project.

This project is focused on learning the Go `net/http` ecosystem by implementing core framework features from scratch instead of relying on full-featured libraries.

# Current features

- Route registration
- Middleware chaching
- Basic Dispatch
- Http error handling

## Quickstart

### Requirements
- Go `1.25.7` or newer

### Run locally

1. Clone the repo
2. Enter the project directory
2. Install dependencies by `go mod tidy` 
3. Run the app by `go run main.go`
